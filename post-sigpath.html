Building SigPath solo: why a shopping tool needed a blockchain

Oct 2026 Solana × Superteam Germany Next.js Rust 2 min read

Online marketplaces are full of listings that are too good to be true. For the Solana × Superteam Germany hackathon I built SigPath on my own: it searches live listings, shows the best price with shipping included, checks every listing for scam signs, and lets you pay through an on-chain escrow.

My role: a solo project.

Four questions for every listing

Each listing gets one verdict, built from four checks:

Price. Is it plausible for its condition, compared with identical live listings?
Photo. Is the same picture used by other sellers?
Account. Is the seller's account brand new?
Reports. Has a verified buyer reported this seller for fakes?

The result is SigPath-checked, Look closer (with the reason), or Not price-checked when there's nothing to compare against. The page says plainly that "checked" means checked, not guaranteed. A scam checker that overpromises isn't helping anyone.

Why a blockchain, and not just a database

"Why crypto?" needed an answer that a normal database can't give. Three parts of SigPath qualify.

Escrow instead of trust. You pay in USDC into an escrow program on Solana. The seller is only paid once the order is fulfilled. If it isn't, anyone can trigger the refund, and the money can only go back to the buyer. You don't have to trust the seller, or me.

Reports only from real buyers. Only the wallet that paid for an order can report it, with a live photo of what arrived, and the seller gets 7 days to reply before a report can be upheld.

Penalties that follow the seller. An upheld finding is published to the Solana Attestation Service under the seller's marketplace handle, so anyone can check it without trusting SigPath's own database. Verified sellers earn a badge token that can't be transferred or sold, and an upheld report burns it.

Every layer, one person

Building solo meant every layer was mine: a Next.js 14, React and TypeScript front end on Vercel, two Anchor programs in Rust, the eBay Browse API for real listings from eBay Germany, Google Gemini for Ai-chan the shopping assistant, a browser extension, price-drop alerts and a German / English interface.

Payments run on Solana devnet, the test network, so you can try the whole flow without real money.

What I'm taking away

If a product uses a blockchain, start from what genuinely has to work without trusting anyone: here, holding the money and recording penalties. Everything else, like search and the scam checks, stays ordinary web code.
